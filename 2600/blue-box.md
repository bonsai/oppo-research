# Blue Box

## Research focus

- 2600 Hz tone
- in-band signaling
- MF signaling
- Blue Box の構造と利用
- Steve Wozniak / Steve Jobs
- phone phreaking との関係

## Historical note

Blue Box は、旧来の電話網で使われた信号音を利用して長距離電話網を制御する装置として知られる。Steve Wozniak と Steve Jobs が Blue Box を製作・販売したことは Computer History Museum 等の資料で確認する。

## P2 relevance

「番号を検索する」のではなく、番号・音声・ネットワークを介して未知の相手や情報へ接続する通信文化の前史として扱う。
